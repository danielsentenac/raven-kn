# S250818k / AT2025ulz

S250818k is an LVK sub-threshold candidate (FAR 6.8 × 10⁻⁸ Hz, probability > 99 % of a sub-solar-mass
component). AT2025ulz was found in its sky map, with host redshift z = 0.0848 (DESI). `examples/s250818k_case.py`
runs RAVEN-KN on the public sky maps from GraceDB.

Pre-discovery ZTF limits were shallower than the transient, so the merger-time window is the 7-day
fallback.

## Distance

| | Distance |
|---|---|
| Host (Planck18) | 400 Mpc (370–386 Mpc for H0 = 73–70), ±5 Mpc from peculiar velocity |
| GW along the host direction, BAYESTAR | 272 ± 74 Mpc, 90 %: 153–395 Mpc |
| GW along the host direction, Bilby | 266 ± 70 Mpc, 90 %: 153–383 Mpc |

P(D > 400 Mpc) = 3–4 % in the GW maps: a tension of about 1.8–2σ. The distance used is the conditional
posterior along the host direction (`conditional_distance`); the map's DISTMU / DISTSIGMA columns
(218 / ~80 Mpc) are parameters of an ansatz, not a mean and standard deviation.

## Joint FAR

| Terms | Joint FAR |
|---|---|
| time only | 14.8 / yr |
| time + sky | 0.22 / yr |
| time + sky + distance | 1.8–2.5 / yr |

The host lies beyond the reference horizon (362 Mpc for a BNS, 172 Mpc for chirp mass 0.5), so the
distance factor is only approximate.

## Would a targeted search trigger?

No. The expected network SNR at 400 Mpc is 3.3 for a BNS and 1.6–2.5 for chirp masses 0.5–0.87 M☉
(approximate O4c ranges).

Not done: GW parameter estimation with the sky position and distance fixed to the host, which would test
directly whether the GW data allow 400 Mpc.

AT2025ulz was later classified as a type IIb supernova (SN 2025ulz); its link to S250818k is still debated.
